# Claude Code 怎么开通：国内用户绕开海外信用卡，从订阅到终端登录一次跑通

搜「Claude Code 怎么开通」的人，卡住的地方一般不是安装。装它只要一条命令，复制粘贴就完事。真正让人卡住的是下一步：终端里敲下 `claude`，提示你登录，你才发现手里这个账号压根没有跑 Claude Code 的资格。

所以「开通」这件事要拆成两半。前面一半是让账号拿到付费订阅资格，后面一半是把终端里的 Claude Code 连到这个账号上。国内用户的麻烦几乎全在前一半：不是不会点按钮，而是付款页反复提示被拒。

## Claude Code 没有独立的价格

先把这个认知纠正掉，能省掉不少无效搜索。

Claude Code 不是单独售卖的产品，它跟着 Claude 的付费订阅走。免费版完全不含 Claude Code，这也是很多人装完却用不了的直接原因。要跑起来，至少得是 Pro，往上还有 Max 5x、Max 20x，以及面向组织的 Team 和 Enterprise。

订阅一个，两处可用：网页、桌面端和手机 App 里的 Claude，加上终端里的 Claude Code。额度也是共享的，用量上限在两边一起算。关于这一点，Anthropic 官方帮助文档写得比较清楚，Pro 和 Max 都是「Claude 与 Claude Code 共用一个用量池」。

换句话说，你搜「Claude Code 怎么开通」，等价于在搜「Claude 付费订阅怎么在国内付款」。

## 开通要走的四步

如果你能正常付款，流程本身没什么难度，大概四步。

**第一步，把账号升到付费档。**在 Claude 官方升级页选择 Pro 或 Max。注意 Max 目前只有月付，没有年付选项，Pro 有年付，折下来大约是每月 17 美元。

**第二步，装 CLI。**官方给了两种方式：一行原生安装脚本，或者用 npm 装 `@anthropic-ai/claude-code`。用 npm 的话先确认 Node.js 版本在 18 以上，装完跑一次 `claude --version` 看看有没有版本号返回。

**第三步，认证。**在项目目录里执行 `claude`，第一次启动会让你选登录方式，选订阅账号那一项，浏览器会自动打开授权页，走完授权，终端会显示登录的是哪个邮箱。

**第四步，检查。**敲 `/status`，如果登录方式那一栏写的是你的订阅计划，而不是 API 计费，说明接上了。想确认自己还剩多少额度，去设置里的用量页看，官方不公开具体数字，只有这里能看到真实余量。

如果一开始是用 API key 登录的，在 Claude Code 里执行 `/login` 就能切回订阅模式。切不过去的话，先 `/logout` 完全退出，再跑 `claude update`，然后把终端整个关掉重开，不要只关标签页。

IDE 也支持，VS Code、Cursor 以及 JetBrains 系列的 IDE 都能装扩展，登录方式和终端一样。注意 IDE 里的用量和终端算同一份额度。

## 国内用户真正卡住的三件事

**支付。**这是最常见的坎。国内银行发行的 Visa、Mastercard 明明有余额，在海外订阅页却提示失败。原因通常不是钱的问题，而是发卡地区、账单地址、支付通道和风控的综合判断。虚拟卡以前是绕路方案，但可用性时好时坏，开卡费加充值手续费也是一笔成本。

**环境和地区。**注册时的 IP、DNS 解析、浏览器时区语言这些细节，在风控眼里是一组信号。用机房 IP 的机场节点，通过率天然偏低。

**稳定性担忧。**社区里关于账号风控的讨论从来没停过，拼车、共享号、低价成品号这些方案的翻车案例也不少。这类方案的共同点是：账号不完全归你，随时可能换号或者失效。

## 第三方代订这类平台在里面做什么

像 BeWild（WildAI）这样的平台，解决的不是模型能力问题，而是「国内怎么把这笔钱付出去」这一步。需要说清楚的是，它是第三方订阅辅助服务，不是 Anthropic 官方渠道，这个定位在多个第三方评测里都被明确写过。

它的操作流程大致是这样：

1. 注册平台账号，按提示在 Chrome 或 Edge 里装官方插件。插件的作用是在你浏览 Claude 时获取登录凭据（Cookie），也就是说，你不需要把账号密码交给平台。
2. 在本地网络环境达标的前提下提交订单。平台会在付款前检测 IP 类型、DNS 泄露和浏览器指纹；住宅 IP 的通过率明显高于机房 IP，这是流程里最关键、也最容易被忽略的一步。
3. 用微信或支付宝完成支付，不用外卡，也不用充值 USDT。
4. 平台代为完成订阅，多数情况下几分钟内生效，也有资料提到 10 到 30 分钟这个区间，具体看订单排队情况。开通后你的原账号本身升级为付费档，聊天记录和历史都在自己账号里。

续费和取消都在平台后台操作，不用再去官方订阅页处理。

价格方面，社区里的说法比较一致：是按官方正价收，再收几美元的手续费。LINUX DO 上有用户直接写过「bewild 靠谱，应该都是实体卡充的，都是按正价来的，大概收几刀的手续费」。另外有第三方整理提到，BeWild 也提供面向 Claude Code / Codex 的按量付费或订阅制方案，并称相比官方定价最多可省 17% 到 50%。这类比例宣传建议只当参考，实际能省多少取决于你选哪个方案和当期活动，最终还是要看下单页的实付金额。

## 三条路怎么选

除了代订，常见的还有另外两条路，适合的人群不太一样。

| 方案 | 适合谁 | 主要代价 |
| --- | --- | --- |
| 官方直接订阅 | 有可用海外卡、支付一直正常的人 | 需要自己处理地区与支付环境 |
| 第三方代订（如 BeWild） | 支付反复失败、不想折腾外卡和账单地址的人 | 属于第三方渠道，需自行确认续费、退款条款，对环境检测有要求 |
| API 计费 | 用量小、或者要跑自动化脚本的人 | 按 token 付费，重度使用成本不可控 |

判断标准其实很简单：你每个月在 Claude Code 里消耗的时间多不多。偶尔改改代码、问问代码逻辑，Pro 一个月 20 美元够用。如果几乎每个工作日都在跑，下午经常被用量截断，那多出来的 80 美元换的是「不被打断」，Max 5x 更划算。真正需要 Max 20x 的是整天挂着跑、或者同时开多个会话和多智能体任务的用法。

有个参考数字值得一提：有第三方分析引用 Anthropic 公开的使用成本数据，说企业部署里平均每个开发者每个活跃日约 13 美元，折算下来每月 150 到 250 美元，这个区间其实已经高过 Max 5x 的月费了。所以如果你是天天用的重度用户，订阅制通常比 API 更可控。

## 开通之后，三个容易被忽略的坑

**环境变量会顶掉你的订阅。**如果你系统里设了 `ANTHROPIC_API_KEY`，Claude Code 会优先用这个 key 认证，结果是按 API 价格计费，而不是用订阅额度。明明刚付了月费，账单却在涨，多半是这个原因。

**额度是共享的。**网页端重度使用会吃掉 Claude Code 的额度，反过来也一样。有人觉得 Claude Code 不够用，其实额度是被别处的长对话消耗掉的。

**第三方渠道的规则要提前看。**续费失败、到期重订、退款处理这些都有先例，操作细节各家不同。下单前花两分钟看清条款，比出问题之后来回沟通省事。

## 常见问题

**Claude Code 能免费用吗？**
不能。免费版完全不含 Claude Code，最低门槛是 Pro 订阅，或者自己配 API key 按量付费。

**一定要上 Max 吗？**
不一定。官方帮助文档的建议是先看自己的用量：Pro 经常在任务中间就被截断，再考虑 Max 5x；只有在 Max 5x 也频繁触顶时，才值得上 20x。

**代订需要交出账号密码吗？**
按现有资料描述，流程走的是浏览器插件获取登录凭据，不需要提供密码。但这仍然属于第三方渠道，账号归属、续费方式和售后边界，建议按你自己的风险偏好判断。

**付款后多久能用？**
多数资料提到几分钟内生效，也有 10 到 30 分钟的说法，取决于订单处理速度。

**开通失败了怎么办？**
先排查两件事：本地环境是否被判定为异常（IP 类型、DNS 泄露、指纹），以及是不是从错误入口进的。如果都正常，在平台后台提交工单或申请退款是标准路径。

**想取消呢？**
代订渠道一般是在平台后台手动取消续订，不需要去官方设置页操作。

最后回到最开始那个问题：开通 Claude Code 这件事，技术含量其实在付款那一步，而不是安装命令。把资格拿到、把 CLI 连上、用 `/status` 确认一次，剩下的就是写代码了。
